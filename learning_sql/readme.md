Este repositorio contiene fundamentos y mis prácticas de SQL como parte de mi ruta hacia ciberseguridad y análisis de datos.

## Contenido
- Creación de base de datos CyberLab
- Tablas: users y devices
- Consultas con SELECT, WHERE, LIKE, ORDER BY, LIMIT, DISTINCT, AND, OR, NOT.
- Consultas con IS NULL, IS NO NULL, MIN, MAX, COUNT, SUM, AVG, IN, AS, CONCAT, GROUP BY, HAVING, CASE, IFNULL
- Escritura de datos.
- Uso de INSERT INTO, UPDATE, DELETE
- Uso de CREATE DATABASE, DROP DATABASE
- Escritura de tablas y uso de constraint.
- CREATE TABLE xxxxx (value int, value varchar(100), value date);
- Constraint: NOT NULL, PRIMARY KEY, CHECK, DEFAULT, AUTO INCREMENT.
- DATETIME CURRENT_TIMESTAMP
- DROP TABLE
- ALTER TABLE: ADD, RENAME COLUmn x TO x, MODIFY COLUMN, DROP COLUMN.
- Relaciones entre tablas: 1:1, 1:n, n:m, Autoreferencisa
- Consulta de datos relacionales: JOIN (INNER, LEFT, RIGHT, FULL) Y UNION
- Algunos conceptos avanzados como INDEX (Primario, Único y Compuesto), TRIGGER, VIEWS, STORAGE PROCEDURE, TRANSACCIONES, CONCURRENCIAS.
